# Original Astral Fantasy character art

This character pack is original local SVG illustration authored for Astral Fantasy. It uses new cubic-curve line art, painted colour gradients, fine hair strands, clothing folds, miniature constellation embroidery, carved metal ornaments, and a subtle alpha-safe grain finish. None of these portraits embeds, crops, traces, recolours, or reuses the supplied reference character images.

The cast shares an illustration language; each roster member has separately authored body, hair, face and costume contours. Lyra's emotion assets preserve pose, clothes, silhouette and registration while changing actual eye, eyebrow and mouth paths.

## Source and verification

- Reproducible source: `tools/art/original_characters.py`; Python standard library only.
- Budget: $0. No image-generation service, paid API, remote artwork request, stock art or external raster asset is used by this pack.
- Runtime format: transparent scalable SVG, with no baked lettering or interface controls.
- Preview PNGs in `tools/art/original-*.png` are local raster renders of these SVGs for visual inspection; they are not additional source artwork or shipped runtime assets.
- Visual checks include the complete Lyra portrait, enlarged facial details, all four expressions side by side, the five-member roster and the matching world sprite.
- The earlier reference-derived WebP portraits have been removed from the runtime asset directory. Supplied JPEGs remain design references only.

The drawing style is anime-influenced vector illustration. These files are editable artwork and remain crisp at any display size.
